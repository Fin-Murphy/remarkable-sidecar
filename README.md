# REMARKABLE SIDECAR

This is a swift-based (mac-native) application for turning your remarkable 2 e-ink tablet into a second monitor sidecar, via USB or Wifi as desired.
It has all the same basic use cases as any other sidecar: reference sheets, extra info, etc. Since it's e-ink, it is best used for test-based applications. 

My current use for it is as a claude terminal. I have my claude display separately in the e-ink terminal while all the rest of my work lives on the screen in front of me.
